# ₊°˖.⟡ ݁. Spectator – Brush Studio⋆°.⊹ ݁₊*。݁

A client-side previewer, inspector and exporter for Procreate (`.brush`, `.brushset`) and
Photoshop (`.abr`) brushes. Everything runs in your browser, and your files are never uploaded.

**Use it:** https://keimbio.github.io/Spectator/. `INSTRUCTIONS.md` has a step-by-step guide.

## Features

**Library**
- Load `.brush`, `.brushset` and `.abr` files from the Import button, or drop them on the Brushes panel.
- Brush set order and names are kept exactly as stored. Both XML and binary `brushset.plist` are supported.
- Dual brushes stay whole, and their secondary shape and grain are shown.
- Grid or List view, with 1–6 columns. Shift-click selects a range of brushes.

**Brush details**
- The settings view is laid out like Procreate's Brush Studio: stroke path, stabilization, taper,
  shape, grain, rendering, wet mix, color dynamics, dynamics, Apple Pencil, properties and materials.
- Values are shown the way Procreate shows them: percentages with meters, On/Off states, named
  modes, and degrees.
- Shape and grain sources are named. A source is either an imported image stored in the brush or
  a named shape from Procreate's built-in library.
- By default only the settings a brush uses are listed. A switch shows the rest.
- About this brush: author, creation date, brush set, file details and the author's signature.

**Export brushes**
- Shape and grain PNGs, split a set into single `.brush` files, or package a new `.brushset`.
- `.abr` tips to PNG (the reliable Photoshop route), and an experimental `.abr` → `.brush` converter.

**Export previews**
- PNG, JPEG, WEBP, TIFF (with transparency) or PDF, with a live preview.
- Layouts: separate files, a grid (choose columns and rows), stacked columns or strips of rows.
- Backgrounds: none, white, black or a custom color. The color picker includes the Spectator palette
  and searchable Pantone TCX and Resene libraries.
- Brush color set to auto-contrast, original or custom, so white strokes never vanish.

**Settings**
- Dark, light or match-system appearance.
- Five color themes, each with dark and light versions. Adding a theme takes six hex codes.
- Background: none, an aura in the theme's colors, four photo presets, or your own uploaded image
  (stored in this browser only). Background dimming.
- Text font and text size.

## Project layout

```
index.html              the app; generated by build.py, don't edit it directly
build.py                assembles index.html from src/ and checks the JavaScript
src/
  template.html         page skeleton
  body-main.html        header, brush panel, brush details, settings
  body-export.html      export window and color picker
  styles.css            main styles (theme colors come from CSS variables)
  export.css            export window styles
  js/config.js          version, repository link, background presets, fonts
  js/themes.js          color themes and the theme color engine
  js/core.js            file readers: binary/XML plists, .brush, .brushset, .abr
  js/decoder.js         turns Brush.archive values into Brush Studio settings
  js/export.js          export window, image rendering, color picker
  js/ui.js              main window, brush details, settings, wiring
  data/brush-schema.json  parameter map (procreate-brush-decoder v1.7)
  data/colour-libs.js     color picker libraries
lib/                    JSZip and jsPDF, bundled locally
fonts/                  Hanken Grotesk (woff2) and its license
assets/brand/           logo, app icon and favicon
assets/backgrounds/     background presets and their thumbnails
```

No CDN is used. To change the app, edit files in `src/`, then run `python3 build.py`.
The build requires Python 3. Node.js is optional and adds a JavaScript syntax check.
Settings live in `localStorage`, and an uploaded background image lives in IndexedDB.
